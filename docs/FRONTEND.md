# Frontend & UX Specification

## Design System Tokens
- **Visual Aesthetic**: Minimal, restrained, light/dark mode support, zero neon visual noise.
- **Accents**: Emerald Green (`#059669` / `#10b981`) and Ethiopian Warm Gold (`#d97706`).
- **Responsive Layout**: Priority on 360px+ mobile viewports with fixed bottom nav, desktop sidebar nav, skeleton loaders, and non-blocking toast notifications.
