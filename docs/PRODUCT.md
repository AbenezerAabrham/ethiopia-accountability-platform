# Product Specification — Ethiopia Accountability Platform

## Target Experience & Flow
1. **Landing Page (`/`)**: Value proposition and onboarding trigger.
2. **Onboarding (`/onboarding`)**: 5-step interactive profile setup, interest selection, experience tiering, intent declaration, community matching.
3. **Home Command Center (`/home`)**: Today's accountability routines checklist, goal summary progress, partner activity, community updates.
4. **Goals & Routines (`/goals`, `/goals/[id]`)**: Dynamic streak calculation algorithm, check-in history, proof evidence attachments.
5. **Communities & Discover (`/discover`, `/communities/[slug]`)**: Community posts, challenges, announcements, resources, members.
6. **Direct Messages (`/messages`)**: 1-on-1 private messaging with block/report capabilities.
7. **Moderation Admin (`/admin`)**: Metrics overview, safety report resolution queue, audit logs.
